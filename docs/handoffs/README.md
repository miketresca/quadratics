# Handoffs

This folder stores resumable session notes for work that may need to continue in a later thread.

Handoffs should be concise, task-named, and should capture:

- active branch and latest pushed commit
- current product intent
- files touched
- known local-only artifacts or ignored files
- next safe steps

Keep durable product decisions in `docs/decisions/`, solved issue notes in `docs/solutions/`, and the active backlog in `docs/backlog/to-do.md`.
