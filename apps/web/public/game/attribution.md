# Game Asset Attribution

Sprint 1 uses small local prototype assets shaped around the supplied Super Smash Bros. references. These files are isolated behind `apps/web/lib/game/assets.ts` so they can be replaced by extracted/optimized archive assets later without changing gameplay code.

Reference sources:

- Super Smash Bros. N64 model archive index: https://models.spriters-resource.com/nintendo_64/ssb/
- Captain Falcon model reference: https://models.spriters-resource.com/nintendo_64/ssb/asset/308409/
- Jigglypuff model reference: https://models.spriters-resource.com/nintendo_64/ssb/asset/288709/
- Luigi model reference: https://models.spriters-resource.com/nintendo_64/ssb/asset/287702/
- Master Hand model reference: https://models.spriters-resource.com/nintendo_64/ssb/asset/283437/
- Smash Ball model reference: https://models.spriters-resource.com/wii/ssbb/asset/292971/
- Super Smash Bros. N64 sounds reference: https://sounds.spriters-resource.com/nintendo_64/ssb/

Legal status: `prototype_reference`. Replace before any production launch that needs licensed/original assets.
